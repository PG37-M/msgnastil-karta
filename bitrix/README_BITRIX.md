# Карта реализованных объектов МСГ НАСТИЛ — установка на Bitrix

Что получится: объекты заводятся как обычные элементы инфоблока. Карта и все фильтры (вид настила, отрасль, страна, город, поиск) строятся из этих элементов автоматически. Добавили элемент → он появился на карте и в фильтрах. Кэш сбрасывается сам при сохранении элемента.

Пакет не проверялся на вашей установке «Аспро Корп 3» — я не видел ваш сайт. Поэтому: сделайте резервную копию (или работайте на тестовой копии), а блок сначала поставьте на отдельную тестовую страницу.

## Шаг 1. Загрузить файлы на сайт

В архиве папка `local/`. Её нужно положить в **корень сайта** (рядом с папкой `bitrix`). Если папка `local` на сайте уже есть, содержимое просто сливается с ней, ничего не затирается (обновления Аспро в `local` ничего не трогают).

Файлов около 700 (подложки карты), поэтому проще всего:
- через панель хостинга (файловый менеджер): загрузить zip-архив в корень сайта и нажать «Распаковать»;
- или по FTP/SFTP;
- или попросить поддержку хостинга распаковать архив в корень сайта (это минута).

Админка Bitrix для этого не подходит: она не умеет загружать папки и архивы.

Проверка: в браузере откройте `https://ваш-сайт/local/msg-map/assets/msg-map.js` — должен показаться код, а не ошибка 404.

## Шаг 2. Выбрать инфоблок

Вариант А (рекомендую): использовать уже существующий инфоблок «Проекты» (из блока «Результат нашей работы»). Тогда у объекта сразу есть страница «Подробнее». Свойства карты добавляются к нему.

Вариант Б: создать отдельный инфоблок. Контент → Инфоблоки → Типы инфоблоков → выберите тип → «Добавить инфоблок». Ссылку «Подробнее» тогда нужно отключить (параметр компонента «Показывать кнопку Подробнее» = выкл).

ID инфоблока: Контент → Инфоблоки → Типы инфоблоков → нужный тип: ID виден в списке (или в адресной строке при редактировании инфоблока: `IBLOCK_ID=…`).

## Шаг 3. Создать свойства (автоматически)

Администрирование → Настройки → Инструменты → **Командная PHP-строка**. Вставьте (подставив свой ID) и нажмите «Выполнить»:

```php
define('MSG_IBLOCK_ID', 12);
require $_SERVER['DOCUMENT_ROOT'] . '/local/msg-install/setup_properties.php';
```

Создадутся свойства: Точка на карте (MAP), Город (CITY), Регион (REGION), Страна (COUNTRY), Вид настила (PRODUCT, несколько значений), Отрасль (INDUSTRY), Задача (TASK), Решение (SOLUTION), Год (PERIOD).

Если свойство «Привязка к Яндекс.Карте» у вас не настроено (не задан ключ API Яндекс.Карт), добавьте перед `require` строку `define('MSG_COORDS_AS_TEXT', true);` — тогда координаты вводятся текстом `широта,долгота`, например `55.75,37.62`. Скопировать их можно в Яндекс.Картах: правый клик по точке → координаты.

Фото объекта — стандартная «Картинка для анонса» элемента (или детальная), её создавать не нужно.

## Шаг 4. Загрузить 40 готовых кейсов (по желанию)

Там же, в Командной PHP-строке:

```php
define('MSG_IBLOCK_ID', 12);
require $_SERVER['DOCUMENT_ROOT'] . '/local/msg-install/import_cases.php';
```

Кейсы создаются **неактивными**: откройте, проверьте точку на карте и отрасль, добавьте фото и включите. Чтобы включить сразу все, добавьте `define('MSG_IMPORT_ACTIVE', true);` перед `require`. Повторный запуск дубликатов не создаёт. Отрасль у кейсов проставлена предварительно, проверьте.

## Шаг 5. Поставить карту на страницу

Сначала создайте тестовую страницу (Контент → Структура сайта → Файлы и папки → создать страницу, например `/map-test/`), откройте её «как PHP» и вставьте:

```php
<?$APPLICATION->IncludeComponent(
    'msg:objects.map', '',
    [
        'IBLOCK_ID' => 12,          // ← ваш ID
        'THEME'     => 'dark',      // dark | light — тема по умолчанию (посетитель может переключить)
        'VIEW'      => 'mercator',  // mercator — плоская карта, globe — глобус
        'SHOW_LINK' => 'Y',         // кнопка «Подробнее» → страница элемента
        'CACHE_TYPE' => 'A',
        'CACHE_TIME' => 3600,
    ]
);?>
```

Если коды свойств отличаются от стандартных, их можно переопределить параметрами `PROP_MAP`, `PROP_PRODUCT`, `PROP_INDUSTRY`, `PROP_COUNTRY`, `PROP_CITY`, `PROP_TASK`, `PROP_SOLUTION` и т.д. (см. `.parameters.php`).

Когда на тестовой странице всё хорошо, тот же вызов вставляется на главную в нужное место. Как именно собирается главная в вашей теме, зависит от настроек Аспро: самый простой способ — вставить вызов в файл главной страницы или во «включаемую область» (в режиме правки «как PHP»).

## Что делать, если не работает

- Блока нет на странице: проверьте ID инфоблока и что есть хотя бы один **активный** элемент с заполненной точкой на карте.
- Карта серая или пустая: откройте консоль браузера (F12) и посмотрите, нет ли ошибок 404 на файлы `/local/msg-map/...` — значит файлы загружены не в корень сайта.
- Новые элементы не появляются: сбросьте кэш (Настройки → Производительность → Управление кэшем → «Очистить кэш») или проверьте, включён ли «управляемый кэш».
- Кракозябры вместо русского: напишите, какая кодировка у сайта; компонент конвертирует из `LANG_CHARSET`, но на нестандартных сайтах это стоит проверить.
- Карта слишком тёмная/светлая или нужен другой цвет меток: все цвета в начале файла `local/msg-map/assets/msg-map.css`.

## Как добавлять объекты дальше

Контент → Инфоблоки → ваш инфоблок → «Добавить элемент»: название, фото, город, страна, поставить точку на карте, вид настила, отрасль, задача, решение. Сохранить. Всё.
