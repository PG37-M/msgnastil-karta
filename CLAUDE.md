# Интерактивная карта реализованных объектов — МСГ НАСТИЛ

Структура:
- `prototype/` — автономный прототип (MapLibre GL: плоская карта и глобус, Leaflet-запас). Запуск: `prototype/start-windows.bat` или `python3 -m http.server` в папке prototype. Основной код: `prototype/assets/msg-map.js`, `msg-map.css`.
- `bitrix/` — пакет для Битрикс «Аспро Корп 3» (компонент `msg:objects.map`, скрипты создания свойств и импорта кейсов, README_BITRIX.md). Копии msg-map.js/css в `bitrix/local/msg-map/assets/` нужно синхронизировать с prototype.
- `prototype/data/` — 40 реальных кейсов (objects.json), страны, тайлы рельефа (data/relief, data/relief-light; генератор tools/make_relief.py).

Принятые решения (не менять без запроса): открытие на плоской карте без объёма (наклон кнопкой); тема по умолчанию тёмная, выбор не запоминается; глобус при открытии приподнят так, чтобы были видны «Казахстан» и объект на Чукотке; светлая тема — страны с объектами светлые, остальное синее; маркеры — капли с решёткой.
Статус Bitrix-пакета: не проверен на реальном сайте.
