# Интерактивная карта реализованных объектов МСГ НАСТИЛ — прототип

Открыть: запустить любой статический сервер в этой папке (`python3 -m http.server`) и перейти на `index.html`.
(Из `file://` не заработает — браузер блокирует `fetch`.)

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | демо-страница-заглушка с блоком карты |
| `assets/msg-map.js`, `assets/msg-map.css` | сам блок (без зависимостей, кроме `vendor/`) |
| `data/objects.json` | **демо-данные** (33 условных объекта, 24 города) — заменить на реальные |
| `data/countries.json` | границы стран (Natural Earth 1:50m, ~1,4 МБ, при gzip ≈ 400 КБ) |
| `data/relief/` | синяя подложка с рельефом: 341 плитка WebP (≈3 МБ, масштабы 0–4), сделана из Natural Earth «Gray Earth» скриптом `tools/make_relief.py` |
| `vendor/` | MapLibre GL 5.6 (глобус), Leaflet 1.9 + markercluster (2D-запас) |

## Подключение на страницу

```html
<link rel="stylesheet" href="/local/msg-map/assets/msg-map.css">
<div class="msgmap" data-msgmap
     data-src="/local/ajax/msg_map.php"            <!-- или статичный objects.json -->
     data-countries="/local/msg-map/data/countries.json"
     data-vendor="/local/msg-map/vendor/"></div>
<script src="/local/msg-map/assets/msg-map.js"></script>
```

Блок грузит MapLibre и данные лениво — только когда подходит к экрану (запас 500 px).
Дополнительные атрибуты: `data-mode="2d"` — принудительный 2D (Leaflet); `data-relief="0"` — без рельефа; `data-relief-tiles` — путь к плиткам; `data-projection="globe"` — вернуть глобус.
Брендирование: цвета — CSS-переменные `--mm-*` в начале `msg-map.css`.

## Формат данных

```json
{ "objects": [{
  "id": 1, "title": "Название объекта", "city": "Москва", "region": "Москва", "country": "Россия",
  "lat": 55.75, "lon": 37.62, "product": "Сварной настил", "period": "2024",
  "photo": "/upload/…jpg", "url": "/projects/case-1/", "sort": 100, "active": true
}]}
```

Объекты одного города (`city` + `country`) автоматически объединяются в один маркер с числом-бейджем,
карточка получает «Москва — 4 проекта», стрелки и номера. Кнопка «Подробнее» показывается только при заполненном `url`.
Страны вне России добавляются просто строками в этот же файл — код менять не нужно.

## Битрикс (черновик, не проверялся на живом сайте)

Инфоблок «Реализованные объекты», свойства по таблице из ТЗ:
`CITY` (С), `REGION` (С), `COUNTRY` (С), `LAT`/`LON` (Ч), `PRODUCT` (С/список), `PERIOD` (С),
`LINK` (С); фото — `PREVIEW_PICTURE`; активность и порядок — стандартные `ACTIVE` и `SORT`.

```php
<?php // /local/ajax/msg_map.php
require $_SERVER['DOCUMENT_ROOT'].'/bitrix/modules/main/include/prolog_before.php';
\Bitrix\Main\Loader::includeModule('iblock');
$out = [];
$rs = CIBlockElement::GetList(['SORT'=>'ASC'], ['IBLOCK_ID'=>MSG_MAP_IBLOCK_ID,'ACTIVE'=>'Y'], false, false,
  ['ID','NAME','SORT','PREVIEW_PICTURE','PROPERTY_CITY','PROPERTY_REGION','PROPERTY_COUNTRY','PROPERTY_LAT','PROPERTY_LON','PROPERTY_PRODUCT','PROPERTY_PERIOD','PROPERTY_LINK']);
while ($e = $rs->Fetch()) {
  $out[] = ['id'=>(int)$e['ID'],'title'=>$e['NAME'],'city'=>$e['PROPERTY_CITY_VALUE'],'region'=>$e['PROPERTY_REGION_VALUE'],
    'country'=>$e['PROPERTY_COUNTRY_VALUE'],'lat'=>(float)$e['PROPERTY_LAT_VALUE'],'lon'=>(float)$e['PROPERTY_LON_VALUE'],
    'product'=>$e['PROPERTY_PRODUCT_VALUE'],'period'=>$e['PROPERTY_PERIOD_VALUE'],'url'=>$e['PROPERTY_LINK_VALUE'],
    'photo'=>$e['PREVIEW_PICTURE'] ? CFile::GetPath($e['PREVIEW_PICTURE']) : null,'sort'=>(int)$e['SORT']];
}
header('Content-Type: application/json; charset=utf-8');
header('Cache-Control: public, max-age=600');
echo json_encode(['objects'=>$out], JSON_UNESCAPED_UNICODE);
```

Координаты можно проставить однократно геокодером по полю «Населённый пункт» (например, Nominatim/Яндекс) и сохранить в `LAT`/`LON`.

## Что реализовано по ТЗ

Плоская карта в синей гамме с рельефом (веб-меркатор): зум (колесо, +/−, pinch), перетаскивание, подлёт к России при загрузке; режим глобуса сохранён как опция; фирменный маркер (капля с иконкой решётки),
пульсация и hover; кластеры с числом объектов; карточка рядом с маркером (справа/слева, не выходит за экран, следует за картой,
закрывается крестиком, Esc, повторным кликом или кликом по карте); на мобильном — bottom-sheet; несколько объектов в городе;
кнопка «домой» (возврат ко всей России; на телефоне — к европейской части и Уралу); запасной 2D-режим на Leaflet при отсутствии WebGL;
ленивая загрузка; на тач-устройствах карта двигается двумя пальцами и не блокирует прокрутку страницы.

## Выделение стран с объектами

Страны, в которых есть хотя бы один активный объект, автоматически «поднимаются» над остальными: объёмная плита с тенью,
подсветка и яркий контур. Выбор делается по полю `country` из данных (русские названия сопоставляются со списком в `msg-map.js`,
константа `COUNTRY_EN`). Для страны, которой нет в списке, добавьте объекту поле `"country_en": "Название на английском"`
как в Natural Earth. Камера слегка наклонена (по умолчанию 26°) — кнопка с «плитой» справа переключает объёмный вид / вид сверху;
наклон меняется атрибутом `data-pitch` (0 — без объёма).

## Два вида карты

- **Плоская** (по умолчанию): `data-projection="mercator"`, с наклоном и объёмными странами.
- **Вид сверху на полюс** (глобус, как в референсе): `data-projection="globe"` — меридианы сходятся к полюсу, подписи градусов вдоль сетки.
  На глобусе страны с объектами выделяются подсветкой и ярким контуром (объёмная плита пока работает только на плоской карте).
На демо-странице вид переключается ссылками над картой (`index.html` и `index.html?proj=globe`).

## Цвета

Палитра задаётся в CSS-переменных `--mm-*` (интерфейс, карточка, маркеры) и в `tools/make_relief.py` (цвета самой подложки:
списки `c_land`, `c_rus`, `c_oc`). После правки палитры подложку нужно пересобрать:
`python3 tools/make_relief.py GRAY_50M_SR_OB.tif data/countries.json data/relief` (исходный растр — Natural Earth, «Gray Earth with Shaded Relief and Water»).

## Чего нет / что проверить

- **Детализация рельефа.** Подложка собрана из данных 1:50 млн: хорошо читается на уровне страны и региона, а при зуме на город становится размытой (границы и метки остаются чёткими). Для более детального вида нужны тайлы высот/рельефа большего разрешения.
- **Подписи городов** на карте не выводятся (только при наведении/в карточке): для текста в WebGL нужны шрифтовые файлы, их можно добавить на следующем этапе.
- Проверено в Chromium (программный рендер): десктоп, мобильный размер, 2D-режим. Safari/Firefox и реальные телефоны — на тестирование.
- **Границы.** Взяты из Natural Earth; для сайта компании стоит осознанно выбрать нужную трактовку спорных территорий и при необходимости подменить `countries.json`.
- Данные — демонстрационные: названия «Демо-объект №…», годы и виды продукции сгенерированы. Реальный референс-лист пока не получен.

## Фильтры и переключение вида (версия 3)

- Кнопка «Фильтры» слева сверху открывает панель: поиск, вид настила, отрасль, страна, город, список найденных объектов. Панель можно открыть и закрыть в любой момент; выбор фильтров сразу меняет метки и подводит карту к найденному.
- Кнопка со значком глобуса/карты справа переключает «плоская карта ↔ глобус (вид с полюса)». Фильтры при этом сохраняются.
- Новое необязательное поле объекта `industry` (отрасль) — в демо заполнено предварительно, проверьте формулировки. Для Bitrix — свойство-список INDUSTRY.
- Вид настила определяется по полю `product` (сварной / прессованный / решётчатый).

## Тёмная и светлая тема (версия 4)

- Кнопка с луной/солнцем справа переключает тему. Выбор запоминается в браузере (localStorage). Тема по умолчанию — атрибут `data-theme="dark"` или `"light"` у блока `.msgmap`.
- Светлая подложка рельефа лежит в `data/relief-light/`. Пересборка: `python3 tools/make_relief.py GRAY_50M_SR_OB.tif data/countries.json data/relief-light light`.
- Цвета обеих тем — CSS-переменные в начале `assets/msg-map.css` (блоки `.msgmap` и `.msgmap[data-theme="light"]`).
